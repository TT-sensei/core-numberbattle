# コアバトル

数字カードを組み合わせて、コアの数字をねらう計算バトル。

今回は、これまでの学習アプリよりも「ゲームとして遊びたくなること」を重視して開発しているプロジェクトです。

## このゲームについて

「計算問題を解く」のではなく、「計算して戦う」ことを中心にしています。

手札の数字カードを＋・−で組み合わせ、敵のコアにどれだけ近づけるかを考えて攻撃します。

「この手札ならどう組む？」
「何枚使う？」
「今はカードをリセットする？」

といった判断もゲームの中に入っています。

## 現在のルール

- プレイヤーHP：20
- コア：15〜25
- 手札：1〜9の数字カード4枚
- 使える計算：＋・−
- 使うカード：1〜4枚
- 最終結果：0以上
- コアを超えるとこうげきしっぱい
- コアとの差が11以上でもこうげきしっぱい

敵は難易度によって変わります。

- かんたん：敵HP 25／4ターンごとにこうげき／3ダメージ／ナビアン
- ふつう：敵HP 30／3ターンごとにこうげき／3ダメージ／エボナビ
- むずかしい：敵HP 35／2ターンごとにこうげき／4ダメージ／ボスナビ

敵をたおしてもバトルは終わりません。次の敵が登場し、プレイヤーHPを引き継いで連戦します。プレイヤーHPが0になるとゲーム終了です。

### ダメージ

コアとの差によってダメージが変わります。

- 0：CORE BREAK
- 1〜2：5ダメージ
- 3〜4：4ダメージ
- 5〜6：3ダメージ
- 7〜8：2ダメージ
- 9〜10：1ダメージ
- 11以上：こうげきしっぱい

さらに、使ったカードの枚数によってボーナスがあります。

- 1〜2枚：+0
- 3枚：+1
- 4枚：+2

コアを超えた場合や、コアから遠すぎた場合はプレイヤーが敵の反撃を受けます。

## カードリセット

毎ターン1回だけ、手札4枚をすべて引き直せます。

「この手札ではねらいにくい」と判断したときに使う、ゲーム上の選択肢です。

## 難易度

スタート画面で「かんたん」「ふつう」「むずかしい」から選択できます。

難易度は、敵のHP・反撃の頻度・反撃ダメージ・登場するナビアンの系統に影響します。

バトル中は敵をたおすたびに次の敵へ進みます。

## ゲームの方向

現在はまず、ゲームの核となる「数字を使って戦う感覚」を試しています。

今後は実際に遊びながら、

- ナビアンごとの特徴
- コンボや特殊なカード
- 連戦を続けることで生まれるゲーム性
- 属性やその他の追加要素

などを検討していきます。

ただし、最初から要素を増やしすぎず、「計算することが勝つためのプレイになる」ことを大切にします。

## edu-kitとの関係

このゲームは、TT-senseiの教育アプリ開発で使っているedu-kitの設計思想を土台にしています。

ただし、すべてのアプリを同じ方向にするのではなく、このプロジェクトでは意図的にゲーム寄りの設計を試しています。

学習部分をゲームに置き換えるのではなく、計算そのものをゲームの行動にすることで、自然に何度も計算したくなる体験を目指しています。

## 技術

- HTML
- CSS
- JavaScript
- GitHub Pagesで動作する静的構成
- 外部API・バックエンド・データベースなし

外部サービスに依存せず、軽量に動作することを基本としています。

## 開発方針

最初から完成形を決めず、

「つくる → 実際に遊ぶ → 違和感を見つける → 直す」

を繰り返して育てていきます。

今回は特に、計算の仕組みそのものがゲームとして成立するかを確かめながら、少しずつ要素を追加していきます。
