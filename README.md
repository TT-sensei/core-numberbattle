# コアバトル

数字カードを組み合わせて、コアの数字をねらう計算バトルです。

「計算問題を解く」のではなく、計算した結果を使って敵を攻撃します。
手札の数字カードに「＋」「−」をつけ、使うカードを自分で選び、コアの数字にどこまで近づけられるかを考えます。

コアにぴったり合えば、一撃必殺の「CORE BREAK」。
ぴったりでなくても、近づけるほど大きなダメージを与えられます。

## 遊び方

1. 1〜9の数字カードが4枚配られます。
2. 使いたいカードをタップして、「＋」「−」を選びます。
3. 使うカードは1〜4枚。計算結果が0以上になるように組み合わせます。
4. 「アタック！」で攻撃します。
5. コアに近いほど大きなダメージ。ぴったりならCORE BREAKです。
6. 敵を倒すと、次のナビアンとのバトルが始まります。
7. 自分のHPが0になるまで、どこまで連戦できるか挑戦します。

## コアと攻撃

コアの数字は15〜30の範囲から決まります。

攻撃結果は、コアとの差によって決まります。

| コアとの差 | 基本ダメージ |
| --- | ---: |
| 0 | CORE BREAK |
| 1〜2 | 5 |
| 3〜4 | 4 |
| 5〜6 | 3 |
| 7〜8 | 2 |
| 9〜10 | 1 |
| 11以上 | こうげきしっぱい |

CORE BREAKは敵に30ダメージを与え、一撃で倒します。

通常攻撃には、使ったカードの枚数によるボーナスがあります。

- 1〜2枚：ボーナスなし
- 3枚：+1
- 4枚：+2

つまり、「とにかく答えを出す」だけでなく、何枚のカードを使って、どのように組み合わせるかも重要になります。

## カードの生成

毎ターン、コアと手札はセットで生成されます。

ゲーム側では、単純にランダムな4枚を配るのではなく、まず今回のカードの組み合わせ方を内部で決め、その条件でコアを作れる数字カードを生成しています。

そのため、毎回まったく同じ形にはならない一方で、数字を組み合わせてコアをねらうというゲームの中心的な体験が生まれるように設計されています。

また、完成した4枚の手札を全探索し、1〜2枚だけで偶然コアにぴったり一致してしまう組み合わせは作り直します。

「全部足せば終わり」というだけにならず、3〜4枚のカードをどう組み合わせるかを考えられるようにするための仕組みです。

## カードリセット

1ターンに1回だけ、「カードをリセット」を使えます。

手札4枚をすべて新しいカードに引き直します。

「この手札ではコアをねらいにくい」と判断したときに使うことができます。

リセットするか、そのまま考えるかもプレイヤー自身が決めます。

## 連戦

敵を倒してもゲームは終了しません。

次のナビアンが登場し、自分の残りHPを引き継いで戦い続けます。

スタート画面には難易度ごとの最高記録が保存され、どこまで連戦できたかを記録できます。

## 難易度

「かんたん」「ふつう」「むずかしい」の3段階があります。

| 難易度 | 敵HP | 敵の攻撃 | 敵の攻撃力 |
| --- | ---: | ---: | ---: |
| かんたん | 25 | 4ターンごと | 3 |
| ふつう | 30 | 3ターンごと | 3 |
| むずかしい | 35 | 2ターンごと | 4 |

難易度が上がるほど、敵を倒すまでに必要な攻撃と、敵からの反撃への対応が重要になります。

## このゲームで大切にしていること

コアバトルは、計算そのものをゲームの行動にすることを大切にしています。

「正解したらポイントがもらえる」という形ではなく、

「この数字なら、どう組めばいい？」
「あと1近づけるにはどうする？」
「3枚使えばダメージが増える」
「今はリセットした方がいい？」

と、計算しながら判断することが、そのままゲームを進めることにつながります。

計算の速さだけではなく、数字の組み合わせ方や見通しを考えながら遊べる計算ゲームを目指して作っています。
