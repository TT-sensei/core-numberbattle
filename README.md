# コアバトル

数字カードを組み合わせて、コアの数字をねらう計算バトル。

今回は、これまでの学習アプリよりも「ゲームとして遊びたくなること」を重視して開発しているプロジェクトです。

## このゲームについて

「計算問題を解く」のではなく、「計算して戦う」ことを中心にしています。

手札の数字カードを＋・−で組み合わせ、敵のコアにどれだけ近づけるかを考えて攻撃します。

ぴったりをねらうだけでなく、

「この手札ならどう組む？」
「何枚使う？」
「今はカードをリセットする？」

といった判断もゲームの中に入れています。

edu-kitの考え方を土台にしながら、今回はあえてゲーム性を強めています。  
学習アプリとしての分かりやすさや操作性は大切にしつつ、演出・連戦・敵の行動などを使って、「もう一回やりたい」と思える計算ゲームを目指します。

## 現在のルール

- プレイヤーHP：20
- 敵HP：30
- コア：15〜25
- 手札：1〜9の数字カード4枚
- 使える計算：＋・−
- 使うカード：1〜4枚
- 最終結果：0以上
- コアを超えるとこうげきしっぱい
- コアとの差が11以上でもこうげきしっぱい

### ダメージ

コアとの差によってダメージが変わります。

- 0：CORE BREAK
- 1〜2：5ダメージ
- 3〜4：4ダメージ
- 5〜6：3ダメージ
- 7〜8：2ダメージ
- 9〜10：1ダメージ
- 11以上：0

さらに、使ったカードの枚数によってボーナスがあります。

- 1〜2枚：+0
- 3枚：+1
- 4枚：+2

コアを超えた場合や、コアから遠すぎた場合はプレイヤーが3ダメージを受けます。

## カードリセット

毎ターン1回だけ、手札4枚をすべて引き直せます。

「この手札ではねらいにくい」と判断したときに使う、ゲーム上の選択肢です。

## ゲームの方向

現在はまず、ゲームの核となる「数字を使って戦う感覚」を試しています。

今後は実際に遊びながら、

- 敵が力をためて、一定のターンでこうげきする仕組み
- ミスしたときの反撃
- 敵をたおしてもプレイヤーHPを引き継ぐ連戦
- ナビアンごとの特徴
- コンボや特殊なカード
- 連戦を続けることで生まれるゲーム性

などを検討していきます。

ただし、最初から要素を増やしすぎず、「計算することが勝つためのプレイになる」ことを大切にします。

## edu-kitとの関係

このゲームは、TT-senseiの教育アプリ開発で使っているedu-kitの設計思想を土台にしています。

ただし、すべてのアプリを同じ方向にするのではなく、このプロジェクトでは意図的にゲーム寄りの設計を試しています。

学習部分をゲームに置き換えるのではなく、計算そのものをゲームの行動にすることで、自然に何度も計算したくなる体験を目指しています。

## 技術

- HTML
- CSS
- JavaScript
- localStorageを利用する場合はブラウザ内に保存
- 外部API・バックエンド・データベースなし
- GitHub Pagesで動作する静的構成

外部サービスに依存せず、軽量に動作することを基本としています。

## 開発方針

最初から完成形を決めず、

「つくる → 実際に遊ぶ → 違和感を見つける → 直す」

を繰り返して育てていきます。

特に今回は、学習アプリとしての「分かりやすさ」だけでなく、ゲームとしての「もう一度やりたい」を大切にします。
