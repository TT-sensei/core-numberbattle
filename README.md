# コアバトル

数字を組み合わせて、コアの数字をねらう計算バトル。

## 現在のルール

- プレイヤーHP：20
- 敵HP：30
- コア：21〜30
- 手札：1〜9の数字カード4枚
- 使える計算：＋・−
- 最終結果は0以上
- 使うカードは1〜4枚
- コアを超えたら攻撃失敗
- コアとの差が11以上でも攻撃失敗
- コアとの差による基本ダメージ
  - 0：CORE BREAK
  - 1〜2：5
  - 3〜4：4
  - 5〜6：3
  - 7〜8：2
  - 9〜10：1
  - 11以上：0
- カード使用ボーナス
  - 1〜2枚：+0
  - 3枚：+1
  - 4枚：+2
- コアを超えた場合、または遠すぎた場合はプレイヤーが3ダメージを受ける

現在はルールの核を試すため、属性・ダイス・敵側の特殊ルールなどは入れていません。

## 方針

静的なHTML/CSS/JavaScriptだけで動作します。外部APIやバックエンドは使用しません。

まずは「数字を使って戦うこと自体がおもしろいか」を確認し、その後に必要な要素だけを追加していきます。
